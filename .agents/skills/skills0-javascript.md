# JavaScript Skill

Use modern JavaScript, but keep application code understandable.

Rules:
- JavaScript only for YOIBI application code.
- Prefer const/let, optional chaining, nullish coalescing, async/await.
- Avoid TypeScript syntax.
- Avoid unnecessary class abstractions.
- In backend use CommonJS as a project rule even though modern JavaScript also supports ESM.
- Follow ESLint and 4-space indentation.
