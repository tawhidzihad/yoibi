# Accessibility and Responsive Skill

Rules:
- Mobile-first responsive design.
- Verify mobile, tablet, desktop breakpoints.
- Use semantic HTML where appropriate.
- Inputs need labels.
- Errors should be programmatically associated with fields.
- Buttons and links must be keyboard usable.
- Focus states must remain visible.
- Do not rely on color alone to communicate state.
- Prefer simple flex/grid layouts over complex positioning.
